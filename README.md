## 📌 معرفی پروژه

این پروژه یک پل ارتباطی قدرتمند و بدون نیاز به سرور (Serverless) میان پیام‌رسان‌های **تلگرام (Telegram)** و **بله (Bale)** است که روی بستر **Cloudflare Workers** با دیتابیس توزیع‌شده **KV** اجرا می‌شود.

این مخزن شامل نسخه‌های پچ‌شده و بهینه‌سازی‌شده از دو ربات اصلی است:

1. **`Tel-Bale-Chat.js` (پل پشتیبانی دوطرفه):**
   - ارتباط مستقیم بین کاربران تلگرام و ادمین در بله
   - ارسال متن، عکس، ویدیو، صدا، وویس، استیکر، لوکیشن و مخاطب
   - قابلیت پاسخ (Reply) مستقیم ادمین از داخل بله به کاربر در تلگرام
   - پشتیبانی از وب‌هوک آنی (Real-time Webhook) با اعتبارسنجی امنیتی `secret_token`
   - سیستم Polling موازی هوشمند جهت جلوگیری از Timeout

2. **`V-Connect.user.js` (فوروارد خودکار کانال تلگرام به بله):**
   - دریافت خودکار پست‌ها از چندین کانال تلگرام و انتشار در کانال مقصد بله
   - پشتیبانی از متن، عکس، ویدیو، گیف (Animation)، سند، نظرسنجی (Poll)، لوکیشن و استیکر
   - استفاده از کلید مجزای `offset` جهت جلوگیری از Race Condition
   - مدیریت ارورها و ذخیره ۲۰ خطای اخیر جهت عیب‌یابی در پنل مدیریت
   - امکان غیرفعال‌سازی بررسی سرور لایسنس خارجی با متغیر محیطی `REQUIRE_LICENSE=0`

## 🛡️ تغییرات و پچ‌های امنیتی اعمال‌شده (Patch v2)

در این نسخه بازبینی‌های امنیتی و باگ‌فیکس‌های اساسی انجام شده است:

| # | ویژگی / رفع مشکل | توضیح |
|---|---|---|
| **۱** | **امنیت رمز ادمین** | خواندن رمز از `ADMIN_PASSWORD` (Secrets) به‌جای هاردکد بودن |
| **۲** | **محافظت در برابر CSRF** | تولید توکن رندوم در سشن و اعتبارسنجی در تمام درخواست‌های POST |
| **۳** | **محدودسازی تلاش ناموفق (Rate Limiting)** | ۵ تلاش اشتباه → قفل موقت ۱۵ دقیقه‌ای در KV |
| **۴** | **تاییدیه وب‌هوک تلگرام** | اعتبارسنجی هدر `X-Telegram-Bot-Api-Secret-Token` |
| **۵** | **مدیریت سشن‌های همزمان** | ذخیره سشن‌ها در کلید مجزای `session:<uuid>` با انقضای خودکار |
| **۶** | **ماسک کردن توکن‌ها در داشبورد** | پنهان‌سازی بخش عمده توکن‌ها (`1234••••••••ABCD`) در UI |
| **۷** | **جداسازی Offset در V-Connect** | انتقال آفست به کلید مستقل در KV برای جلوگیری از فوروارد تکراری |
| **۸** | **سازگاری MarkdownV1 و Escape کاراکترها** | جلوگیری از نمایش خط فاصله و نقطه به‌شکل `\.` یا ارور پارس HTML/MD |
| **۹** | **مدیریت موازی آپدیت‌ها** | پردازش دسته‌ای با `Promise.all` برای پیشگیری از تایم‌اوت ورکر |
| **۱۰** | **گزارش‌گیری دقیق خطاها** | ثبت دلایل واقعی خطاها از API بله/تلگرام در داشبورد |

## 🚀 راهنمای سریع راه‌اندازی (Quick Start)

### مرحله ۱: ساخت Worker و KV در Cloudflare
1. در پنل کلودفلر وارد بخش **Workers & Pages** شوید.
2. روی **Create Worker** کلیک کرده و نام دلخواه (مثلاً `tel-bale-bridge`) بدهید.
3. در تب **KV** یک KV Namespace به نام `BRIDGE_KV` بسازید.
4. در تنظیمات ورکر (**Settings -> Bindings**) متغیر `KV` را به `BRIDGE_KV` متصل کنید.

### مرحله ۲: آپلود اسکریپت
محتوای یکی از دو فایل را بسته به نیاز خود در ادیتور ورکر کپی و دکمه **Save and Deploy** را بزنید:
- برای چت پشتیبانی: `Tel-Bale-Chat.js`
- برای فوروارد کانال: `V-Connect.user.js`

### مرحله ۳: تنظیم متغیرهای امنیتی (Environment Variables)
در بخش **Settings -> Variables and Secrets**:
```env
ADMIN_PASSWORD = "یک_رمز_ورود_بسیار_قوی"
REQUIRE_LICENSE = "0"        # فقط برای V-Connect جهت عدم وابستگی به سرور لایسنس
WEBHOOK_VERIFY = "1"         # برای تایید اصالت وب‌هوک تلگرام
```

### مرحله ۴: راه‌اندازی و ورود به پنل مدیریت
آدرس ورکر خود را با پسوند `/admin` باز کنید:
```
https://<YOUR-WORKER>.workers.dev/admin
```
با رمز عبوری که در متغیرها قرار دادید وارد شوید، توکن‌های ربات تلگرام و بله را وارد کنید و تنظیمات را ذخیره نمایید.

## ⚙️ استقرار از طریق Wrangler CLI (اختیاری)

اگر ترجیح می‌دهید از طریق خط فرمان دیپلوی کنید:

```bash
# نصب wrangler
npm install -g wrangler

# ورود به حساب کلودفلر
wrangler login

# کپی فایل کانفیگ
cp wrangler.toml.example wrangler.toml

# ساخت KV
wrangler kv:namespace create "KV"

# ست کردن رمز ادمین
wrangler secret put ADMIN_PASSWORD

# استقرار پروژه
wrangler deploy
```
